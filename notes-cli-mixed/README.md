# notes-cli-mixed

The notes command line over [`notes`](../notes) and [`notes-search`](../notes-search), stated in both notations in one crate: the notebook commands (`add`, `list`, `remove`) in Rust, `search` and `docs` in inline Markdown, merged in code into `NotesCliExt`. It states the spec [`notes-cli-rust`](../notes-cli-rust) and [`notes-cli-md`](../notes-cli-md) state.
